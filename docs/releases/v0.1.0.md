# IPsec Client 0.1.0 (pré-alfa)

Primeira versão do **IPsec Client**, um cliente de VPN IPsec para Linux feito
para VPNs **legadas**: IKEv1 em modo agressivo, PSK de grupo + XAuth e grupos
DH antigos, como os de concentradores FortiGate. É o tipo de VPN que os
clientes atuais do Linux já não conseguem conectar.

## Destaques

- **App desktop:** conectar e desconectar com um clique, ver o IP virtual, o
  tempo e o tráfego, e um log que esconde usuário e grupo.
- **Perfis:** importe o `.json` recebido da sua equipe (ou o `swanctl.conf`
  de uma VPN que já funciona) e exporte sem credenciais para os colegas.
- **Credenciais** no chaveiro do sistema (GNOME Keyring/KWallet), nunca em
  disco.
- **Sem Docker:** o app traz o próprio strongSwan 6.1.0. O componente de rede
  é instalado **uma vez**, pelo próprio app, com a senha de administrador.
  Depois disso, conectar não pede senha.
- **Não mexe na sua rede:** rotas e DNS da VPN ficam numa interface própria
  (`ipsc0`). Wi-Fi, Ethernet e outras VPNs não são tocadas.
- **Bandeja e notificações**, diagnóstico do computador com dicas de correção
  e tema claro/escuro.

## Qual arquivo baixar

| Sua distribuição | Arquivo |
|---|---|
| Fedora, RHEL, openSUSE | `ipsec-client-0.1.0-1.x86_64.rpm` |
| Ubuntu 22.04+, Debian 12+, Mint | `ipsec-client_0.1.0_amd64.deb` |
| Outras | `ipsec-client_0.1.0_amd64.AppImage` |

Como instalar, usar pela primeira vez, atualizar e desinstalar:
[manual de instalação](https://github.com/lucastelso/ipsec-client/blob/v0.1.0/docs/instalacao.md).
Recebeu um perfil de um colega? Siga o
[guia rápido](https://github.com/lucastelso/ipsec-client/blob/v0.1.0/docs/guia-rapido.md).

Para conferir o download, na pasta dos arquivos:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

## Limitações conhecidas

- **Pré-alfa:** validado numa VPN FortiGate real (IKEv1 agressivo + PSK +
  XAuth), mas ainda com poucos usuários.
- Só **x86_64**.
- No GNOME, o ícone da bandeja precisa da extensão AppIndicator.
- Fechar a janela fecha o app, mas **não desconecta** a VPN. Use
  **Desconectar**.
- Antes de remover o pacote, remova o componente de rede em **Sistema →
  Componente de rede → Remover**.
- O AppImage precisa da biblioteca FUSE 2 (`fuse-libs` no Fedora, `libfuse2`
  ou `libfuse2t64` no Ubuntu).
- VPNs legadas usam criptografia fraca por natureza. Veja o
  [SECURITY.md](https://github.com/lucastelso/ipsec-client/blob/v0.1.0/SECURITY.md).
