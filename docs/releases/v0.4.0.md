# IPsec Client 0.4.0 (pre-alpha): a new look

*Leia em português: [v0.4.0.pt-BR.md](https://github.com/lucastelso/ipsec-client/blob/v0.4.0/docs/releases/v0.4.0.pt-BR.md)*

The app has a new interface: the color of the window tells whether the VPN is
on, and the next step is always one big button.

## How to update

1. Install the new package over the old one:
   - Fedora: `sudo dnf install ./ipsec-client-0.4.0-1.x86_64.rpm`
   - openSUSE: `sudo zypper install --allow-unsigned-rpm ./ipsec-client-0.4.0-1.x86_64.rpm`
   - Ubuntu/Debian: `sudo apt install ./ipsec-client_0.4.0_amd64.deb`
   - AppImage: replace the old file with the new one.
2. Open the app. It offers to update the network component (**Update now**):
   nothing in it changed, but it carries the version number. It takes a few
   seconds and asks for the administrator password.

Coming from 0.2.0 or older, read the notes of
[0.3.0](https://github.com/lucastelso/ipsec-client/blob/v0.4.0/docs/releases/v0.3.0.md)
too: it brought important security fixes.

## What changed

- **The top of the connection screen shows the state by its color:** slate
  when disconnected, amber while connecting, **green** when connected,
  **red** when it did not connect. There you also pick the profile and find
  the one action to take now (Connect, Cancel, Disconnect, Enter
  credentials).
- When something fails, a card below says **what happened and what to do**;
  the technical details stay folded.
- The connection shows in big numbers: virtual IP, time, received and sent.
- The tabs (Connection, Profiles, System) moved to the bottom of the window.
- The first use numbers its two steps.

## Accessibility

- Text contrast meets WCAG AA in both themes.
- Every control shows keyboard focus.
- Screen readers hear the dialogs' close button and the diagnostic levels in
  the interface language.
- The system's "reduce motion" setting is honored.

## Tested distributions

Ubuntu 22.04 and 24.04, Debian 12 and 13, Fedora 45, openSUSE Tumbleweed and
AlmaLinux 10 (with EPEL). RHEL 9 and its rebuilds are not supported.

| Your distribution | File |
|---|---|
| Fedora, openSUSE, RHEL/Rocky/AlmaLinux 10 (with EPEL) | `ipsec-client-0.4.0-1.x86_64.rpm` |
| Ubuntu 22.04+, Debian 12+, Mint | `ipsec-client_0.4.0_amd64.deb` |
| Others | `ipsec-client_0.4.0_amd64.AppImage` |

To check the download, in the folder with the files:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

Guides: [installation](https://github.com/lucastelso/ipsec-client/blob/v0.4.0/docs/installation.md)

## Known limitations

- **Pre-alpha:** validated on a real FortiGate VPN (IKEv1 aggressive + PSK +
  XAuth), but still with few users.
- **x86_64** only.
- On GNOME, the tray icon needs the AppIndicator extension.
- Closing the window closes the app, but **does not disconnect** the VPN.
