# IPsec Client 0.2.0 (pre-alpha): security, privacy and languages

*Leia em português: [v0.2.0.pt-BR.md](https://github.com/lucastelso/ipsec-client/blob/v0.2.0/docs/releases/v0.2.0.pt-BR.md)*

This version fixes a **local privilege escalation** in the network component,
adds privacy improvements and makes the app bilingual (English and
Portuguese). Everyone using 0.1.0 should update.

## How to update (important)

1. Install the new package over the old one:
   - Fedora: `sudo dnf install ./ipsec-client-0.2.0-1.x86_64.rpm`
   - Ubuntu/Debian: `sudo apt install ./ipsec-client_0.2.0_amd64.deb`
   - AppImage: replace the old file with the new one.
2. Open the app. In **System → Network component**, click **Update** and type
   the administrator password.
3. Connect as usual.

**The security fix lives in the network component.** Without step 2, it is
still the 0.1.0 one. If you try to connect before updating, the app warns you
and offers the **Update network component** button.

## What was fixed

- **Local privilege escalation.** In 0.1.0, a malicious program running as
  your user could, without a password, make the app's strongSwan run a command
  as root. It could not be exploited from the network or by the VPN gateway: a
  malicious program had to be running on the computer already. Now the
  embedded strongSwan ignores commands coming from the user's side.
- **Isolation between users of the same computer.** Only whoever connected can
  disconnect the VPN, read its log and talk to its strongSwan.
- **Extra protection of the network service:** no access to disks, kernel
  settings or other processes.

Technical details: [ADR-0019](https://github.com/lucastelso/ipsec-client/blob/v0.2.0/docs/adr/0019-forced-updown-and-if-id.md)
and [SECURITY.md](https://github.com/lucastelso/ipsec-client/blob/v0.2.0/SECURITY.md).

## New

- **English and Portuguese.** The app follows your system language; change it
  in **System → Appearance → Language**.
- **Copy anonymized:** the log button replaces the gateway address, IPs, DNS
  servers and your organization's domains with placeholders (`<gateway>`,
  `<ip-1>`, `<domain-1>`), so you can send the log when asking for help
  without exposing your work network. Check the text before sharing it. In the
  terminal: `ipsec-client-cli logs --anonymize`.

## Which file to download

| Your distribution | File |
|---|---|
| Fedora, RHEL, openSUSE | `ipsec-client-0.2.0-1.x86_64.rpm` |
| Ubuntu 22.04+, Debian 12+, Mint | `ipsec-client_0.2.0_amd64.deb` |
| Others | `ipsec-client_0.2.0_amd64.AppImage` |

Prefer the `.rpm` or the `.deb`. The AppImage carries its own libraries (such
as WebKitGTK), which do not get your distribution's security updates.

To check the download, in the folder with the files:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

Guides: [installation](https://github.com/lucastelso/ipsec-client/blob/v0.2.0/docs/installation.md)
· [quick start](https://github.com/lucastelso/ipsec-client/blob/v0.2.0/docs/quick-start.md).

## Known limitations

- **Pre-alpha:** validated on a real FortiGate VPN (IKEv1 aggressive + PSK +
  XAuth), but still with few users.
- **x86_64** only.
- On GNOME, the tray icon needs the AppIndicator extension.
- Closing the window closes the app, but **does not disconnect** the VPN. Use
  **Disconnect**.
- Before removing the package, remove the network component in **System →
  Network component → Remove**.
