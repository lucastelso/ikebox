# IPsec Client 0.6.0 (pre-alpha): profile editor

*Leia em português: [v0.6.0.pt-BR.md](https://github.com/lucastelso/ipsec-client/blob/v0.6.0/docs/releases/v0.6.0.pt-BR.md)*

Profiles can now be created and edited in the app, starting from a vendor
template, without writing JSON.

## How to update

1. Install the new package over the old one:
   - Fedora: `sudo dnf install ./ipsec-client-0.6.0-1.x86_64.rpm`
   - openSUSE: `sudo zypper install --allow-unsigned-rpm ./ipsec-client-0.6.0-1.x86_64.rpm`
   - Ubuntu/Debian: `sudo apt install ./ipsec-client_0.6.0_amd64.deb`
   - AppImage: replace the old file with the new one.
2. Open the app. It offers to update the network component (**Update now**):
   nothing in it changed, but it carries the version number. It takes a few
   seconds and asks for the administrator password.

Coming from 0.2.0 or older, read the notes of
[0.3.0](https://github.com/lucastelso/ipsec-client/blob/v0.6.0/docs/releases/v0.3.0.md)
too: it brought important security fixes.

## What changed

- **Profile editor.** In **Profiles → New**, pick what the VPN looks like:
  **FortiGate**, **Cisco Easy VPN**, **IKEv2 with a PSK** or **blank**, and
  fill in what the gateway administrator gave you. The pencil next to a
  profile edits it.
  - The encryption is picked by name ("modern", "compatible", "legacy"), each
    with its security badge, or typed exactly as the gateway has it in
    **Advanced**.
  - The editor says, field by field, what is missing or wrong, and the
    security badge and its reasons update while you type.
- **One-time codes:** a profile can say that the XAuth password is a code
  from a token or a phone app. The app then asks for it at every connection
  and never stores it.
- **Profile format 2** underneath. Profiles that use nothing new are still
  saved in format 1, so colleagues on older versions can import what you
  export. Only a profile with a one-time code needs 0.6.0 to be imported.

## Tested distributions

Ubuntu 22.04 and 24.04, Debian 12 and 13, Fedora 45, openSUSE Tumbleweed and
AlmaLinux 10 (with EPEL). RHEL 9 and its rebuilds are not supported.

| Your distribution | File |
|---|---|
| Fedora, openSUSE, RHEL/Rocky/AlmaLinux 10 (with EPEL) | `ipsec-client-0.6.0-1.x86_64.rpm` |
| Ubuntu 22.04+, Debian 12+, Mint | `ipsec-client_0.6.0_amd64.deb` |
| Others | `ipsec-client_0.6.0_amd64.AppImage` |

To check the download, in the folder with the files:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```

## Known limitations

- **Pre-alpha:** validated on a real FortiGate VPN (IKEv1 aggressive + PSK +
  XAuth); the other modes are validated against test gateways only.
- No EAP or certificates yet: they come in the next phases (ADR-0023 and
  ADR-0024).
- **x86_64** only.
- On GNOME, the tray icon needs the AppIndicator extension.
- Closing the window closes the app, but **does not disconnect** the VPN.
